## 📖 Описание

**Russian Fishing 4 Bot** — программа, которая автоматизирует рыбалку в Russian Fishing 4. Выбираете способ ловли, настраиваете по понятной инструкции, и бот берёт рутину на себя, а каждый улов приходит скриншотом в ваш Telegram.

### ✨ Возможности

#### 🎣 Поддержка основных видов ловли
- ⚙️ **Спиннинг**
  - равномерная проводка
  - твичинг на воблеры и топвотеры
  - джиговая ловля
- 🎈 **Поплавочная ловля**
- 🔔 **Доночная ловля (фидер)**

#### 🌊 Морская ловля
- ⏳ Находится в процессе разработки

#### 📲 Telegram-уведомления
- 📸 Отправка скриншотов каждого улова в ваш личный Telegram-чат

#### ⚙️ Удобство
- 🛠️ Простой интерфейс и понятная пошаговая инструкция по настройке

### 🚀 Быстрый старт

1. Приобретите ключ на [официальном сайте](#-где-приобрести)
2. Скачайте и запустите программу
3. Введите лицензионный ключ
4. Следуйте пошаговой инструкции по настройке и (по желанию) подключите Telegram
